# vps.sh

Скрипт для быстрой первичной настройки VPS на Debian/Ubuntu: обновляет систему, ставит удобные утилиты, настраивает редактор micro, устанавливает Zsh с плагинами через Zinit и промпт Starship с пресетом Gruvbox Rainbow.

## Возможности

- Обновление системы и установка базовых пакетов: `micro`, `zsh`, `git`, `curl`, `wget`, `ufw`, `btop`, `fzf`, `zoxide`, `autojump` и др.
- Настройка micro (бинды копирования/вставки, работа с терминальным буфером обмена).  
- Установка шрифта JetBrains Mono Nerd Font и обновление кеша шрифтов для корректного отображения значков в терминале.
- Установка Starship и применение пресета `gruvbox-rainbow` в `~/.config/starship.toml`.
- Установка Zsh как оболочки по умолчанию (`chsh`) и генерация `~/.zshrc` с Zinit и набором плагинов.
- Продвинутая история, алиасы и автоматическое переключение в Zsh в конце работы скрипта.

## Установка

Запусти на сервере:

```
bash <(wget -qO- https://raw.githubusercontent.com/arpicme/vps.sh/refs/heads/main/vps.sh)
```
