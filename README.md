# 🚀 VPS Setup Script (`vps.sh`)

Универсальный и безопасный скрипт для первичной настройки свежего сервера на базе **Debian** или **Ubuntu**. Превращает «голую» систему в мощную, удобную и красивую рабочую среду с настроенным терминалом, набором необходимых утилитами и автоматическими обновлениями.

Скрипт идемпотентен: его абсолютно безопасно запускать как на свежеустановленной ОС (скрипт сам исправит пути и репозитории), так и использовать для обновления текущей конфигурации.

## ⚡ Установка и запуск

Выполните эту команду в терминале (от пользователя `root`):

```bash
bash <(wget -qO- https://raw.githubusercontent.com/arpicme/vps.sh/refs/heads/main/vps.sh)

```

## ✨ Главные возможности

* **Современный Shell:** Оболочка Zsh по умолчанию в связке с быстрым менеджером плагинов **Zinit**.
* **Умный терминал:** Установлен и настроен кроссплатформенный промпт **Starship** с применением пресета `gruvbox-rainbow`.
* **Полная автоматизация:** Все системные диалоги отключены (non-interactive). Настройка происходит в один клик без зависаний на экранах конфигурации.
* **Шрифты и иконки:** Автоматическая загрузка, распаковка и установка `JetBrains Mono Nerd Font` для идеального отображения глифов в консоли.
* **Безопасность и автономность:** Автоматическое исправление `PATH`, подключение расширенных репозиториев (`contrib`, `non-free`) на чистом Debian и настройка еженедельных автообновлений через Cron.

## 🛠 Что устанавливается под капотом

Процесс разделен на 10 последовательных шагов, ход выполнения которых сопровождается аккуратным спиннером:

1. **Подготовка окружения:** Экспорт правильных путей для `/sbin` и `/usr/sbin`, включение всех веток репозиториев.
2. **Обновление системы:** Тихое полное обновление пакетов (`apt full-upgrade`).
3. **Установка инструментария:** `micro`, `sudo`, `curl`, `wget`, `git`, `ufw`, `btop`, `socat`, `zstd`, `unzip`, `net-tools`, `cron`, `fzf`, `zoxide`, `autojump`.
4. **Настройка времени:** Принудительная установка часового пояса **UTC** (совместимо с LXC/Docker контейнерами).
5. **Конфигурация редактора micro:** Установка горячих клавиш для комментирования и удобного копирования/вставки через терминальный буфер обмена.
6. **Оформление:** Развертывание Starship и обновление кэша шрифтов (`fc-cache`).
7. **Оболочка Zsh:** Смена дефолтной оболочки (`chsh`), генерация продвинутого `~/.zshrc` с умной историей (поиск по префиксу).
8. **Плагины Zinit:** Автодополнения, подсветка синтаксиса, интеграция истории и автопереходов (`zsh-autosuggestions`, `zsh-syntax-highlighting`, `fzf-tab`, `zoxide`, `fzf-history-widget`).
9. **Фоновые задачи:** Регистрация безопасного Cron-задания для тихого обновления системных пакетов раз в неделю с логированием в `/var/log/apt_autoupdate.log`.
10. **Финальная очистка и запуск:** Применение плагинов, обновление кэша Zinit и бесшовный вход в новую Zsh-сессию.

## 💻 Предустановленные алиасы и функции

В сгенерированном `.zshrc` уже настроены удобные сокращения для ускорения рутинных задач:

| Команда | Описание |
| --- | --- |
| `up` | Быстрое и тихое обновление системы (`apt update && apt full-upgrade -y`) |
| `scu` | Повторный запуск этого скрипта для быстрого обновления среды (`vps.sh`) |
| `zup` | Глубокое обновление менеджера Zinit и всех установленных плагинов |
| `mi` | Запуск текстового редактора `micro` |
| `mzh` | Быстрое открытие файла конфигурации `~/.zshrc` в редакторе |
| `szh` | Перезагрузка конфигурации Zsh (`source .zshrc`) в текущем окне |
| `ls` | Цветной вывод каталогов (`ls --color=auto`) |
| `rwe` | Быстрый доступ к CLI внутри контейнера `remnawave` |

### Управление Docker (Remnawave / Remnanode)

Скрипт включает встроенные bash-функции для быстрого управления специфичными контейнерами:

* `rwr` — Перезапуск контейнеров в текущей рабочей папке (`docker compose down && up -d`) с выводом логов.
* `rwu` — Загрузка новых образов (`pull`), перезапуск контейнеров и вывод логов.
* `upw` — Каскадное выполнение: обновление ОС (`up`) + обновление Docker-контейнеров (`rwu`).
